# Learn Playwright Batch 2x

A hands-on repository for learning **Playwright** with **JavaScript** fundamentals. Covers core Playwright basics, JavaScript concepts, identifiers, literals, and more.

## Contents

| Chapter | Topic | Files |
|---------|-------|-------|
| 1 | Playwright Basics | `01_Basics.js`, `02_JS.js`, `03_Verify_setup.js`, `04_Hotcode.js` |
| 2 | JavaScript Concepts | `05_JS_Basics.js` |
| 3 | Identifiers & Literals | `06_Identifier_Rules.js`, `07_identifier_part2.js` |
| - | Comments | `08_comments.js` |

## Setup

1. Clone the repo
2. Install dependencies: `npm install`
3. Run tests: `npx playwright test`
